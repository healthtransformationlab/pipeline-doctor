# Decision records

A decision record (ADR) says what we decided, why, and what would make us revisit it. Action items say what
still has to be done. They are kept apart: a decision lives in `docs/adr/NNNN-slug.md` (numbered, never
renumbered, superseded by a later ADR rather than rewritten); an action item is a GitHub issue labelled
`action-item`, closed when the work merges. An issue may ask for a decision to be made or written down; the
decision goes in an ADR and the issue is closed by the PR that adds it. Copy `template.md` to the next number.
